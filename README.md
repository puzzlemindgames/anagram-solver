# AnagramCraft: High-Performance Anagram Solver & Scramble Word Finder

AnagramCraft is an open-source client-side anagram unscrambler and word generator designed for Scrabble, Words With Friends, Wordle and daily word puzzles.

## Key Features

- **Wildcard Tile Support:** Accepts `?` or `*` to represent blank Scrabble tiles with automatic substitution.
- **Advanced Position Filters:** Narrow down matches by prefix, suffix, contained letters or exact character length.
- **Official Tournament Scoring:** Calculates exact Scrabble tile values for every candidate word.
- **Grouped Word Output:** Displays words grouped cleanly by length with one-click clipboard copying.
- **Zero Server Latency:** Runs entirely in-browser using fast frequency-matching algorithms.

## Deployment to GitHub Pages

To publish on GitHub Pages:

1. Push this repository to `https://github.com/puzzlemindgames/anagram-solver.git`.
2. Go to repository **Settings → Pages**.
3. Under **Branch**, select `main` and root `/` folder.
4. Click **Save**.

Your tool will be live at `https://puzzlemindgames.github.io/anagram-solver/`.
